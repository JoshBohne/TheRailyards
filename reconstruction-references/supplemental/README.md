# Supplemental references

`unofficial-home-plate-skyline.jpg` was supplied by Josh during the V13 audit-repair goal. Josh explicitly identifies it as **not official**. It is a conceptual baseball-field composite with a Chicago skyline and a Chicago Fire building at right.

Use it to help assess skyline character, visual density, and the composition from behind home plate. Do not treat the apparent field placement, surrounding facilities, dimensions, or sightlines as authoritative stadium design or surveyed geography. Official AECOM/Crane's renderings remain the primary stadium references; geographic positions require their own evidence. If this image conflicts with those references, record the difference rather than blending incompatible geometry.
