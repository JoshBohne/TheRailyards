# V3 remaining source-backed elements

This is the finite follow-up list after the current v3 pass. I compared the canonical AECOM B4 north aerial, A3 bridge-facing view, and B6 south aerial with `railyards-v3/detail-north.png` and `railyards-v3/detail-bridge.png`, then checked the owning v3 modules. The source boxes below use native pixels in the named source file. They are image-plane regions, not surveyed dimensions.

`detail-south.png` is not used as current-state evidence here because the south render is being regenerated. The active hall and Northwestern Medicine edits are also excluded from discrepancy claims: their modules changed after the rendered north image, so they need a fresh render before a fair audit. Rows below either identify geometry that is still absent from an owning module or a visible mismatch that remains after the module exists.

## Deliberately held out

The Northwestern Medicine bar/wing and north entertainment hall are source-resolved, but their owning modules changed after the current north render and are still in active work. They should be scored against a new render rather than duplicated here. The skyline is retained as a low-confidence framing layer: the supplied concept views support density and value structure, but not enough identity or geometry to justify a new remaining-element row before the near-field items above hold.

The bridge and public-realm elevation values remain implementation priors. In particular, Roosevelt's road/sidewalk candidate must stay distinct from the private covered rail crossings; source pixels establish adjacency and visual ordering, not a surveyed grade profile.
