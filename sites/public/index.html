Read this correctly

A possible future,
not a prediction.

This project can make relative scale, sightlines, routes, and modeled distances easier to understand. It cannot establish final architecture, construction feasibility, official field dimensions, access, safety, or what will ultimately be approved.

Referenced

Visible directly in published source material.

Reconstructed

Connected from multiple sources, measurements, or geographic data.

Interpretive

Illustrative

Behind the build

Astra calibrated and generated the first scene. Fable audited the weak spots, corrected the geography and architecture, rendered the routes, and built toward the browser replay. The separate build log covers the prompts, versions, validation, failures, and an instrumented token snapshot.
